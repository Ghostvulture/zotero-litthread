## 连接与模型

在右上角齿轮进入设置。API 地址填写服务的 HTTPS 基础地址，例如 `https://api.deepseek.com` 或以 `/v1` 结尾的地址；不要填写完整的 `/chat/completions` 路径。其他自定义路径不在当前支持范围内，仅本机开发服务允许 HTTP。

将 Key 填入密码输入框并保存。留空保存会保留已有 Key；「清除 Key」删除当前 API 地址的 Key。切换 API 地址后需为新地址配置对应 Key。Key 优先保存在 Zotero 登录管理器，不可用时界面会提示仅本次会话有效。

点击「测试连接」只发送一句测试消息，不附带论文。模型列表由本机维护，展开「可选模型列表」后可按行或逗号分隔填写；不会自动查询服务商模型清单。底部选择的模型用于下一次请求。默认值和预置项可自行改成账户当前可用的模型。

问答使用非流式 Chat Completions；生成完后一次显示，120 秒超时，可点击停止。API 服务按自己的规则计费。

### DeepSeek 余额

保存官方 API 地址和 Key 后，在设置页余额区点击刷新。插件调用 `GET /user/balance`，展示货币、总余额、充值余额、赠送余额及查询时间。不会自动轮询；切换页面和模型不会触发查询。

余额请求不附带论文或对话。第三方兼容服务的余额接口暂不支持，也不会把它的 Key 转发到 DeepSeek。截图里的 110 元是模拟测试数据。

## 文献与分组

在主窗口选择文献，或在主窗口阅读标签页打开 PDF，找到右侧「研脉 · 科研助手」。普通布局下，输入区上方显示当前文章标题；可在设置页查看附件位置。

顶端下拉菜单选择这次学习所属分组。分组列表显示嵌套名称，但读取的是所选分组的**直接成员**，不会递归混入子分组。也可以选一个不包含当前文章的分组，把当前阅读积累保存到该主题下。

PDF 选中文字后点击「问研脉」，选段和可用的页码会进入侧栏。切换附件不会沿用另一附件的选段。Zotero 7 的独立 PDF 窗口没有这个右侧面板：选文入口可以记住文本，但问答需回到主窗口标签页。

## 聊天与侧栏尺寸

- 顶部：分组、保存入口、设置入口。
- 中部：可独立滚动的聊天区；选中回答文字可以复制。
- 底部：任务、模型、输入框和发送／停止按钮。
- 完成回答末尾：「回到本轮提问」定位到该条回答对应的输入，不清空草稿，也不滚动 PDF。

拖动 Zotero 的侧栏分隔线时，插件根据实际可用宽度重新布局。窄布局将任务与模型分行排列；较宽布局增加横向空间。Zotero 自身可能限制最小侧栏宽度，或在小窗口中将侧栏移到 PDF 下方；插件的高度紧凑模式与宽度适配分别处理。

切换设置页或调整宽度会保留草稿、当前任务、模型和对话。普通问答必须输入内容；预设的笔记、卡片和知识脉络任务可以直接生成，也可以填写额外要求。Ctrl / ⌘ + Enter 发送，Enter 换行。

### Markdown 与公式

支持标题、强调、列表、代码、表格、引用块和 HTTP(S) 链接，以及：

| 类型 | 写法 |
| --- | --- |
| 行内公式 | `$n=42$`、`\(\sigma^2\)` |
| 独立公式 | `$$\frac{\sigma^2}{n}$$`、`\[\sum_{i=1}^{n}x_i\]` |

独立公式可以跨行；常见分数、上下标、矩阵和求和通过内置 KaTeX 转成 MathML，由 Zotero 本地显示。代码中的公式保持源码，`\$` 是普通美元符号；未闭合、错误、不支持或超过预算的表达式回退为原文。长代码、表格和独立公式可在各自区域横向滚动。

原始 HTML 按文本处理，远程图片只显示占位；外部 HTTP(S) 链接只有点击后才打开。保存的 Markdown 保留 LaTeX 源码。

## 从回答到知识文件

| 任务 | 保存内容 | 目录 |
| --- | --- | --- |
| 文献笔记 | 问题、理论、方法、发现和局限 | `notes/` |
| 观点卡片 | 单个论点、适用条件、支持与反对证据 | `claims/` |
| 论证素材 | 研究设计、结果、案例与机制等支撑材料 | `evidence/` |
| 问答摘录 | 另存的回答 | `conversations/` |

点击顶部保存图标，在设置中的「回答与知识卡片」选择类型，填写例如 `主题:因果推断, 方法:随机实验` 的标签，再保存最新回答。卡片包含文献信息、问题、选段与正文，并配套保存 `.sources.json`。其中 `[F001]` 等编号只对应这一次材料包的片段，不能当作可靠 PDF 页码或跨问答引用。

「分组知识脉络」结合目录、已有 memory 与近期卡片生成草稿。核实后手动保存为 memory，保存前会备份旧文件。普通问答和卡片保存不会自动覆盖 memory；插件也没有自动抓取引用／被引关系的功能。

## 文件目录与迁移

默认根目录是 Zotero 数据目录中的 `research-companion`，每个分组再使用 `library-<ID>/collection-<key>/` 隔离。同名分组不会共用目录；分组重命名不改变 key。

设置 → 分组文献与记忆文件夹 → 打开记忆目录，可查看实际位置。指定根目录后，插件仍追加文献库与分组子目录；不会把 memory 写进每一个 PDF 的 storage 文件夹。

**更改根目录不会自动移动旧资料。** 如需迁移，先备份，把整个分组目录复制到新根目录下相同的相对位置，再刷新。不要只移动 `memory.md` 而漏掉卡片、索引和 conversations。

`memory.md` 可手工编辑，下次发送会重新读取。本地对话按分组和文章分别保存，保留最近 40 条消息；每次请求只带有限历史。导出操作生成 `library.json` 和 `library.md`，包含所选分组全部直接成员及本地附件位置；设置页列表只显示前 200 条。

这些文件不会自动进入 Zotero 同步。多设备使用需自行复制或同步知识目录；不同操作系统的附件路径也可能不同。卸载插件不会删除知识文件。

## 一次请求读取的范围

以下是当前实现的近似字符预算，**不是 token 数**；每部分还受总材料预算限制。

| 材料 | 范围 |
| --- | --- |
| 可提取正文 | 读取最多前 120,000 字符；按问题关键词选片段，约 34,000 字符预算 |
| 选中段落 | 约 12,000 字符 |
| 批注 | 前 100 条，约 7,000 字符 |
| memory | 前 5,500 字符 |
| 卡片 | 最近 30 张，每张预截取 1,800 字符，卡片合计约 4,000 字符；与 memory 合并后约 10,000 字符 |
| 分组目录 | 仅知识脉络任务，最多 100 条元数据，约 10,000 字符；不逐篇读正文 |
| 对话历史 | 最近最多 8 条，约 6,000 字符 |
| 当前问题 | 约 6,000 字符 |

这不是全文完整阅读的保证。没有可提取正文时，可以提供选段或已有批注；只有标题和元数据不能支持对论文内容的判断。

## 数据流与权限

插件运行于 Zotero 扩展环境，读取文献元数据、分组、附件位置、全文缓存和批注；索引不足时可能调用 Zotero 的本地全文提取。不会自动下载缺失附件，也不会修改书目字段。

只有点击发送或测试连接才发送模型请求；余额另由手动刷新触发。请求携带的研究材料交给配置中的服务商，没有自动整库上传、遥测或后台轮询。自定义服务地址意味着材料由该服务接收。

路径字段不进入模型材料，常见路径和密钥格式会被过滤；但这不能替代你对手工输入内容的检查。Key 仅用于认证，不写进 memory、卡片或导出。导出的文献目录有意包含附件路径，分享时需自行处理。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 看不到侧栏 | 确认插件启用，在主窗口选择文章或打开 PDF 标签页，展开右侧信息栏；必要时重启 Zotero。 |
| 旧版提示不兼容 | 旧 0.1.0 清单只允许 Zotero 7；使用当前 XPI，并核对插件管理器版本。 |
| 升级后仍是旧界面 | 核对已装版本为 0.3.3，再重开阅读标签页或重启。无需先卸载。 |
| 侧栏无法继续缩窄 | 最小宽度由 Zotero 宿主决定；插件只能适应宿主提供的空间。 |
| 公式显示源码 | 核对成对分隔符、语法及 KaTeX 支持范围；代码中的公式本来就不会渲染。 |
| HTTP 401 | 在插件设置中更新 Key。 |
| HTTP 402 / 429 | 检查账户余额，或稍后重试。 |
| HTTP 400 / 404 | 检查基础地址及模型名称；自定义 API 不保证完全兼容。 |
| 无正文或索引不完整 | 检查附件与 Zotero 全文索引；扫描件先做 OCR，或粘贴所需段落。 |
| 切换目录后历史消失 | 原目录保留；按迁移说明复制整个分组目录。 |
| JSON 文件损坏 | 插件拒绝覆盖原文件；先备份，再修复 JSON 或从备份恢复。 |
